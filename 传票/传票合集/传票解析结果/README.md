## 已知问题与使用提示

- **手写判读**：全部由视觉模型逐张读图完成，非 OCR 引擎输出；连笔字段（科目名、人名、品名）可能误读，每张票的存疑点已写入 `uncertain`，请以票面原件为准。
- **数量/金额列普遍为空**：多数票的数量写在原材料列右侧、金额靠右下角计算式推算，已分别落在 `quantity` 与 `calculations`。
- **上下版说明栏**：已单独用 `plate_note` 字段承载（常有「有反」「连二」「拼」等），与 `plates`（上版才数）区分。
- **客户名称写法不统一**：如「东城/东诚」「澳龙中学部/澳龙中学」「69中二部 刘杨 / 69中二部刘杨」，做统计时建议做归一化。
