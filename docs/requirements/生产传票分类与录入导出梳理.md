# 生产传票分类与录入导出梳理

整理日期：2026-10-20。当前目标只有三件事：弄清生产传票怎样分类、哪些信息需要录入，以及怎样导出可核对的明细和学校汇总。

范围依据为用户最新说明、[沟通纪要](../../metting/meeting-notes.md)、[会议原转写 JSON](../../metting/transcripts/meeting-notes.json)及[传票合集](../../传票/传票合集/)。本稿是样本梳理和业务讨论草案，分类名称、数量解释和导出样式尚需逐项核实，不是已批准规格或系统实现。

## 一 先明确录的是什么

当前只处理生产传票中的印刷生产内容。先把原票看懂，再形成可填写的表格，服务文颖试录、内部查询及学校汇总／结算数据整理。其他类型票保留原资料，本稿不为其梳理业务流程。

**录入不能直接照搬现有解析 CSV 的每一行。** 一张票可能包含多个学校、多个产品；一个产品又可能占几行制版、内页或材料记录。已有 119 份解析的 499 条 `items` 只是识别时划分的行，不等于 499 个独立产品或订单。

建议先分清三个层次：

| 层次 | 表达什么 | 样本说明 |
|---|---|---|
| 原票 | 一张原始传票及其来源 | 原图与印制票号共同定位，图片序号不是票号 |
| 生产业务明细 | 可以独立说明归属、产品和需求的一项生产内容 | 同票不同学校或产品需要分别识别；具体拆分由原文和业务解释确定 |
| 生产构成与材料记录 | 产品的封面／内页、制版、机印量、某一项或多项共享的用纸 | 一条产品可能有多行构成；共享材料只记一次，不能逐产品复制后求和 |

例如，[115](../../传票/传票合集/传票图片/传票_115.jpg)有两种成册产品，各有内页等续行，不能按四个工艺表格行重复计算本数；[113](../../传票/传票合集/传票图片/传票_113.jpg)上半与下半出现不同学校，不能全部归给票头单位。

## 二 生产票怎样分类

### 2.1 建议先按产品内容分类

目前采用一个通用录入结构即可。产品类别作为可选的筛选辅助字段，不给整张传票强制指定一个类别；一票可包含多类产品。当前优先记清具体品名、要求和数量，未分类不阻止这些已确认信息的录入及按学校汇总。下表保留为讨论建议，不急着为每一类另做票据模板。

| 建议类别 | 记录重点 | 原票例子 | 需核实的边界 |
|---|---|---|---|
| 试卷／练习资料 | 科目、纸型、份数或张数、单双面构成 | [051](../../传票/传票合集/传票图片/传票_051.jpg)、[113](../../传票/传票合集/传票图片/传票_113.jpg) | 不能只因出现学科名就确定产品用途；不明确时保留原名待核 |
| 答题卡 | 实际品名、科目、尺寸、印面和数量 | [020](../../传票/传票合集/传票图片/传票_020.jpg)票头有“高一题卡” | 与试卷同票时，各项数量和费用要分别解释 |
| 表单／单据等印刷品 | 表格名称、规格、单双面、张数 | [107](../../传票/传票合集/传票图片/传票_107.jpg)印刷报销单、审批表等 | 产品叫“报销单”不等于发生了报销款项 |
| 本册／手册／记录本 | 本数、成品尺寸、封面／内页构成、装订要求 | [115](../../传票/传票合集/传票图片/传票_115.jpg) | 产品本数与内页、制版和材料行数分别记录 |
| 其他已确认印刷品 | 保留实际品名与要求 | 实际确认为生产后再归类 | 不按客户是不是学校决定它是否属于生产；不把名称不清的票硬塞进此类 |

上述是**分类建议**，不是本厂已经确认的产品目录。无法判断的内容标“待确认”，不参与某类别的确定统计。

### 2.2 工艺与归属用字段表达

| 信息 | 处理方式 |
|---|---|
| 学校、校区、老师、年级、科目 | 归属或业务描述字段，不各自变成一种票型 |
| A4、A3、9K、16K及成品尺寸 | 产品规格字段；不预先编造互相换算关系 |
| 单面、双面、单／双混合 | 印面要求，按原文保留并在解释清楚后拆解 |
| 胶印、速印、复印 | 印刷方式，只有票面或业务解释明确后填写；不能从“有上版栏”直接推断 |
| 装订、胶装、裁切等 | 原票明确的工艺要求，可多项并存；空白不直接等于“不需要” |

现有解析字段 `printing_method` 主要存“单／双”，对应的是印面，不能拿它自动生成“胶印／速印／复印”分类。疑似“胶活”等识别文字也要先回图，不能据误读分类。

### 2.3 另记录入结构 不增加业务票种

为选样和核对，可注明该票是单项、同校多项、跨学校合票，是否含成册续行、共享材料或分组算式。它们是录入结构特征，可以并存，不是互斥的票种，也不直接决定价格。

## 三 录入字段建议

先录看得见的原文，再补经解释的结构化值。第一轮不要求所有栏填满；原票未写、字迹不清、业务含义不明要分别注明，不能统一补零。

第一轮先抓住这些内容：原图与票号、票头及实际归属、可见日期、产品原名、印刷要求原文、材料记录及适用范围、算式／合计原文、核对问题。后文的规范类别、数量、单位和单价等，在解释清楚后补；已明确的可以同时填写，无需先重复抄录再重填。

### 3.1 票头信息 每票记录一次

| 建议字段 | 录入方式与用途 |
|---|---|
| 原图文件／图片序号 | 自动带出或选择，用于回到原票；一票多图时保留全部对应文件 |
| 原传票号 | 按文本保留前导零；辨不清时标待认，不另定新票号制度 |
| 票头订货单位原文 | 照录，不自动覆盖所有业务明细的学校归属 |
| 订货日期原文 | 有则录，空白保持空白 |
| 取货日期原文 | 单独录，不当作已经确认的实际送达日或结算日期 |
| 其他日期／交期备注 | 如另写“某日送到”，保留原文，不覆盖前面日期 |
| 整票备注 | 关联前单、加急、包装、划改等；旁边另写序号也另记，不替代票号 |
| 票面合计原文 | 有则照录及注明涂改／覆盖；只在票级保存一次，不默认最终应收 |
| 整票核对说明 | 哪些内容属于当前生产范围、有哪些疑问、确认后采用什么解释 |

### 3.2 生产业务明细 每项生产内容记录一次

| 建议字段 | 先录什么 | 确认后补什么 |
|---|---|---|
| 明细序号与原票位置 | 在本票中编号，并注明哪块／哪些行属于这一项 | 多行是否确属同一产品 |
| 实际学校／客户与校区 | 明细中的单位原文；与票头不同的明确记出 | 用于归并汇总的规范名称；原文保留 |
| 老师／联系人 | 原票有则录 | 对应哪项业务；不能根据学科名补造老师姓名 |
| 年级／科目 | 有则录；分不清的先保留在品名或要求原文 | 确定后用于筛选，不强制旧票补齐 |
| 产品名称原文 | 照录实际印刷品名 | 必要的规范名称，避免改掉真实产品内容 |
| 产品类别（可选） | 如需分类可参考第二节草案，暂不分类可留空 | 是否使用及具体分类名称，按实际筛选需要确定 |
| 印刷要求原文 | 完整保留数量表达、乘号、单双面、纸型、页数等 | 这是首轮核心，不用猜出的一个“数量”替代原文 |
| 产品规格／成品尺寸 | 能辨清的纸型、开本、尺寸及单位 | 区分成品规格与材料规格 |
| 业务数量与单位 | 先留原始表达，如“某本数＋内页要求” | 明确是份、本、张还是面；必要时另记每份内容量 |
| 印面构成 | 原文中的单／双面和混合要求 | 解释清楚后拆成需要的数量；不默认双面一律乘二计费 |
| 印刷方式 | 明文可知时录胶印／速印／复印，否则待确认 | 按业务解释补录，不由原字段名猜测 |
| 装订等工艺要求 | 票面原文及适用的产品 | 必要的规范含义；成册内页续行不另加本数 |
| 该项核对说明 | 归属、续行、数量、划改和价格哪些还不清楚 | 核对结果和确认依据，便于导出时注明覆盖范围 |

这些是字段组，实际表格不必一次拆成很多独立输入框。例如第一轮可先填“印刷要求原文”，再只拆当前统计必需的规格、业务数量和单位。

### 3.3 生产与用纸信息 按真实记录保存

| 建议字段 | 处理原则 |
|---|---|
| 原票位置与关联范围 | 说明属于整票、某项、某几项，或尚不清楚；不能仅凭落在同一横行就认定归属 |
| 生产构成原文 | 封面、内页等写了就保留；属于同一产品的续行不能当新需求重复计数 |
| 上版说明、才数、次数 | 保留原文；当前不要求全部变成自动计算参数 |
| 机印张数原文 | 乘法、多个数、涂改照录；不直接当客户印数或计费数 |
| 纸张／原材料名称与规格原文 | 保留原意；不能把识别候选中的误读名称直接标准化为真值 |
| 材料侧数量原文 | 对应原票右侧“数量”栏，保留算式、单位及涂改 |
| 已确认用纸数量与单位 | 问清后才补用于统计的数值和单位；未确认不参加求和 |
| 共同用纸的适用范围 | 同一记录只算一次；跨学校尚未分清时，保留为共同用纸，不猜分摊比例 |

**现有 raw 的 `quantity` 应理解为“材料侧数量候选”，不能直接改名为客户订购数量。** 同理，机印张数、成品张数、份数、本数和计费量分别表达不同事情。

### 3.4 算式与金额 保留原文和采用依据

| 建议字段 | 处理原则 |
|---|---|
| 手写算式原文与位置 | 保留划掉、改写、小计、倍数等信息；不默认每个算式都有效 |
| 算式覆盖范围 | 对应一项、几项合算还是整票；未清楚时标待确认 |
| 已确认计费数量与单位 | 与实际生产数量不同时分别记录，不改写真实业务量 |
| 已确认单价及依据 | 原票／有效价目／业务确认；票面无价不补一个通用价 |
| 已确认采用金额 | 注明对应的业务或整票范围，未核准则留待确认 |
| 金额核对说明 | 谁确认、依据是什么、哪些划改有效、是否仍有未分配范围 |

金额可以按以下任一已核实的来源使用：明细／明确分组金额，或明确全归同一学校的整票金额。**同一范围只能选一种金额来源，不能加完明细再加整票合计。** 跨学校只有共同金额而无法分清时，先保留，不生成各校已确认费用。

当前 499 条解析明细的 `amount` 全空，7 张票的合计又含存疑文字。因此本稿不能给出已核准全批次费用，也不以自动乘积覆盖原票的人工确认。

## 四 后续怎样导出

### 4.1 建议先用一个工作簿组织四张表

以下是导出内容草案，尚未制作正式 Excel 模板。目的是方便核对和汇总；具体版式仍需用一组真实票据试填确认。

| 表 | 一行表示什么 | 主要列与用途 |
|---|---|---|
| 生产票总览 | 一张原票 | 原图、票号、票头单位、日期原文、结构特征、票面合计、核对情况；用于回查、查漏和去重 |
| 生产业务明细 | 一项已区分的生产内容 | 原票与位置、实际学校／校区、产品、类别、规格、数量原文、确认业务量／单位、计费依据、采用金额与覆盖范围、待核说明 |
| 用纸明细 | 一条实际材料记录及其适用范围 | 原票与位置、材料原文、确认规格、数量原文、确认数／单位、关联产品或共享范围；防止按产品复制共同用纸 |
| 学校汇总 | 一个学校内同口径的一组统计 | 期间与日期口径、学校／校区、产品类别与规格、数量单位、已核量、已核用纸、已核费用、覆盖票及待核范围 |

同一工作簿分表只是建议，不是要求建设四个系统模块。用纸表也可以作为原票的展开附表，但导出时要能区分一条真实记录与重复展示。

学校汇总内，业务量与用纸量应分区显示：产品按张／份／本等各自统计，材料按纸种／规格／单位分别统计。不要把产品明细与材料明细展开成所有组合后再汇总。

### 4.2 汇总口径

1. **日期先说明。** 导出时写清期间及使用的是哪一个经确认的日期；原票取货日、交期、实际送达日、录入日不互相替代。
2. **归属按明细。** 跨校票分别认定，不能全部归票头；学校简称怎样归并需要确认。
3. **数量同口径才相加。** 张、面、份、本、机印数、材料数不混加，规格不同分别列；换算规则未确认时保留原单位。
4. **共同用纸只计一次。** 同校共用且范围和单位已核实，可以在该校材料区记一次；跨校共享未分清时显示未分配记录，不能任意分给学校。
5. **金额不重复。** 票级合计、分组小计与逐项金额不能重叠计入；原 CSV 把 7 张票的候选合计展开到 32 行，不能直接对那一列求和。
6. **按核实程度分别使用。** 学校和数量已核准但价格未核准时，可以先出用量；金额待确认不妨碍查看原票和明细。
7. **显示统计覆盖范围。** 未核实内容出现在核对明细里；汇总注明待核票／明细与未分配记录，不能把缺值写零，也不能把部分已核费用称为学校完整消费总额。

学校基础用量、用纸和结算数据都属于当前用途；无需先建库存出入库、成本会计、发票或回款流程。

### 4.3 两种导出用途

| 用途 | 当前应呈现什么 |
|---|---|
| 内部核对稿 | 可以包含未确认内容，但保留原文、图号、位置及问题，明确哪些是识别候选 |
| 学校汇总／结算数据稿 | 采用已核实归属与口径，清楚说明覆盖范围；正式对外版式和最终金额仍需业务方核对 |

能导出一个文件不等于数据已经能结算。确认一张简单票和一张复杂票的解释及输出后，再扩展同类票，会更容易发现字段缺失和重复统计。

## 六 还需要得到的答案

当前问题集中在这些方面：产品类别怎么称呼；哪些原行是一项业务；每项归哪所学校；需求量、计费量和材料量各是什么；共同用纸怎样归属；哪些算式及金额有效；导出按哪个日期和哪种学校样表组织。

已确定的是只做生产票的分类、字段和导出梳理，不再回到完整 ERP 范围选择。字段和导出草案可以先拿现有样本逐项讨论，缺少答案的地方标待确认，不强行补完。

本稿未修改原图、解析 JSON、CSV 或生成脚本，未重新 OCR，未制作已批准的正式录入模板，也未进入系统开发。
