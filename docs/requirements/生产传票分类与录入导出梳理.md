# 生产传票分类与录入导出梳理

整理日期：2026-10-20。当前目标只有三件事：弄清生产传票怎样分类、哪些信息需要录入，以及怎样导出可核对的明细和学校汇总。

范围依据为用户最新说明、[沟通纪要](../../metting/meeting-notes.md)、[会议原转写 JSON](../../metting/transcripts/meeting-notes.json)及[传票合集](../../传票/传票合集/)。本稿是样本梳理和业务讨论草案，分类名称、数量解释和导出样式尚需逐项核实，不是已批准规格或系统实现。

**当前工作边界（2026-10-21用户再次明确）：现有传票仅作需求样本，用来理解传票、确定后续录入字段、计算和导出方式。本轮不处理这批业务数据，不开展逐张录入、补齐、清洗、迁移或整批结算。095、115等票的解释作为规则示例保留，不形成该批数据的正式录入记录。**

后续录入方案见[生产传票录入与导出方案讨论稿](生产传票录入与导出方案讨论稿.md)：按四组信息说明夏直接录入、多印刷品的填写及导出示例，已确认规则与新增操作建议分别标注，尚未进入实施。

## 一 先明确录的是什么

当前只讨论生产传票中的印刷生产内容，通过典型样票理解业务，整理后续人工录入、内部查询及学校汇总／结算导出的方案。纪要中的文颖试录是曾讨论的落地路线，当前不因此启动本批样票试录或数据补齐。其他类型票保留原资料，本稿不为其梳理业务流程。

范围补充（2026-10-21）：用户明确，包含多个产品、多个规格的整体印刷需求属于订单层；本期不做订单，以生产传票为起点，梳理票内明细及后续生产、用纸和导出信息，不要求先录订单或关联订单编号。

使用场景已确认（2026-10-21）：由夏负责日常录入，电脑端和手机端均需支持。现有已开好的传票用于分析需要哪些录入字段；后续由夏根据实际业务直接在系统中录入，不先开好纸质传票再补录。两端的具体交互方式、技术形态及其他使用者的操作范围在后续方案中确定。录入后的纸票打印需求另行讨论。

**录入不能直接照搬现有解析 CSV 的每一行。** 一张票可能包含多个学校、多个产品；一个产品又可能占几行制版、内页或材料记录。已有 119 份解析的 499 条 `items` 只是识别时划分的行，不等于 499 个独立产品或订单。

建议先分清三个层次：

| 层次 | 表达什么 | 样本说明 |
|---|---|---|
| 生产传票 | 夏在系统中直接录入的一张生产传票 | 现有纸票仅用于理解其内容；系统编号方式待设计，图片序号不作为新传票编号 |
| 生产业务明细（传票明细） | 本张传票内可以说明归属、产品、规格和数量的一项生产内容 | 同票不同学校、产品或规格需要分别识别；具体拆分由原文和业务解释确定 |
| 生产构成与材料记录 | 产品的封面／内页、制版、机印量、某一项或多项共享的用纸 | 一条产品可能有多行构成；共享材料只记一次，不能逐产品复制后求和 |

当前建议先按“一张传票包含多条传票明细”梳理录入结构。这里的明细不代表上层订单需求；相同产品出现在不同传票中，也不能据此合并为同一条生产明细。是否另有跨票共享的生产记录，仍需具体业务实例说明，不能用订单层的拆分关系直接确定传票与生产详情的数据库关系。

例如，[115](../../传票/传票合集/传票图片/传票_115.jpg)的140本和310本已由用户确认为两项产品的本数，“1＋40”是每本中说明与表格的构成，不能按四个工艺表格行重复计算本数，详见第八节；[113](../../传票/传票合集/传票图片/传票_113.jpg)上半与下半出现不同学校，不能全部归给票头单位。

## 二 生产票怎样分类

### 2.1 建议先按产品内容分类

目前采用一个通用录入结构即可。产品类别作为可选的筛选辅助字段，不给整张传票强制指定一个类别；一票可包含多类产品。当前优先记清具体品名、要求和数量，未分类不阻止这些已确认信息的录入及按学校汇总。下表保留为讨论建议，不急着为每一类另做票据模板。

| 建议类别 | 记录重点 | 原票例子 | 需核实的边界 |
|---|---|---|---|
| 试卷／练习资料 | 科目、纸型、份数或张数、单双面构成 | [051](../../传票/传票合集/传票图片/传票_051.jpg)、[113](../../传票/传票合集/传票图片/传票_113.jpg) | 不能只因出现学科名就确定产品用途；不明确时保留原名待核 |
| 答题卡 | 实际品名、科目、尺寸、印面和数量 | [020](../../传票/传票合集/传票图片/传票_020.jpg)票头有“高一题卡” | 与试卷同票时，各项数量和费用要分别解释 |
| 表单／单据等印刷品 | 表格名称、规格、单双面、张数 | [107](../../传票/传票合集/传票图片/传票_107.jpg)印刷报销单、审批表等 | 产品叫“报销单”不等于发生了报销款项 |
| 本册／手册／记录本 | 本数、成品尺寸、封面／内页构成、装订要求 | [115](../../传票/传票合集/传票图片/传票_115.jpg) | 产品本数与内页、制版和材料行数分别记录 |
| 其他已确认印刷品 | 保留实际品名与要求 | 实际确认为生产后再归类 | 不按客户是不是学校决定它是否属于生产；不把名称不清的票硬塞进此类 |

上述是**分类建议**，不是本厂已经确认的产品目录。无法判断的内容标“待确认”，不参与某类别的确定统计。

### 2.2 工艺与归属用字段表达

| 信息 | 处理方式 |
|---|---|
| 学校、校区、老师、年级、科目 | 归属或业务描述字段，不各自变成一种票型 |
| A4、A3、9K、16K及成品尺寸 | 产品规格字段；不预先编造互相换算关系 |
| 单面、双面、单／双混合 | 印面要求，按原文保留并在解释清楚后拆解 |
| 胶印、速印、复印 | 印刷方式，只有票面或业务解释明确后填写；不能从“有上版栏”直接推断 |
| 装订、胶装、裁切等 | 原票明确的工艺要求，可多项并存；空白不直接等于“不需要” |

现有解析字段 `printing_method` 主要存“单／双”，对应的是印面，不能拿它自动生成“胶印／速印／复印”分类。疑似“胶活”等识别文字也要先回图，不能据误读分类。

### 2.3 另记录入结构 不增加业务票种

为选样和核对，可注明该票是单项、同校多项、跨学校合票，是否含成册续行、共享材料或分组算式。它们是录入结构特征，可以并存，不是互斥的票种，也不直接决定价格。

## 三 录入字段建议

以下讨论夏根据实际业务直接录入时需要表达的信息。原图、原票位置、手写算式和识别核对等留作样本解释，不作为未来录入的前置资料或必填内容。字段名称按实际业务含义组织，未知内容不猜填、不补零。

学校及老师资料的填写要求（2026-10-21用户确认并补充）：学校名称必填；老师姓名原则填写，缺失时允许暂空，不要求先补齐姓名才能录入。校区、学部、年级、学科、学科组、组长、联系方式等其余资料选填。本批样票缺失的姓名不列为当前补齐任务。关系说明见[学校与老师CRM梳理](学校与老师CRM梳理.md)。

产品与生产信息的填写要求已由用户确认：品名、成品规格、成品数量及单位，以及上版信息、机印张数、原材料和预计用纸量等，本版均按选填处理，保存后允许补充、修改。这些字段不作为保存传票的前置条件；单价和金额仍按第3.4节已确认的录入要求处理。

学校、老师的录入方式于2026-10-22调整并确认：每项印刷品分别选择已有学校和该校老师，删除票头统一学校、老师及默认归属。档案的增删改查放在后续后台，取消此前“提醒后随传票新增”的方式；本轮只调整草图和需求说明，不实施后台。

老师按“学校＋姓名”对应已有记录，不同学校的同名老师分别保留；明细只选择该校已有老师，缺失允许暂不选择。档案不存在时由后续后台维护，录票时不自动创建。

学校全称、简称归并到同一学校档案，同时保留每张传票上的原名称；老师匹配中的学校使用归并后的档案，不因学校写法不同重复新增老师。该归并原则已由用户确认，具体学校名称对应关系按实际资料核对。

后续录入围绕学校、老师、订货日期、印刷品名称、规格、成品数量及单位、印面、产品构成、预计用纸、单价和金额组织。具体输入方式继续按业务规则梳理，不要求先把本批样票抄录成表或补齐全部资料。

### 3.1 票头信息 每票记录一次

2026-10-22用户删除录入页第一块“基本信息”中的学校、老师统一填写。以下仅保留票级日期、备注和合计，学校、老师及业务组织归属放在各项印刷品明细。

| 建议字段 | 录入方式与用途 |
|---|---|
| 传票编号 | 标识系统内的生产传票；具体编号规则在后续设计中确定，不要求先有纸票号 |
| 订货日期 | 录入实际订货日期；本版按该日期筛选、归期和汇总 |
| 取货日期 | 已知时填写，不当作实际送达日或结算日期 |
| 其他日期／交期备注 | 已知的送货安排及交期说明，不覆盖订货日期 |
| 整票备注 | 填写实际业务说明，如加急、包装或相关传票等 |
| 整票合计（自动相加） | 汇总各印刷品最终保存的金额，具体规则见第3.4节 |

样本的原图、原票号、票头原文、涂改和票面合计继续作为本文解释业务的证据，不要求夏在新建传票时填写这些样本核对信息。

### 3.2 生产业务明细 每项生产内容记录一次

| 建议字段 | 录入内容 | 处理说明 |
|---|---|---|
| 明细序号 | 标识本票内的各项印刷品 | 产品内部的多行构成不重复增加产品条目 |

| 学部／年级／科目（选填） | 已知时填写实际归属 | 用于筛选，暂缺可留空、后续可补充 |

| 产品类别（可选） | 如需分类可参考第二节草案，暂不分类可留空 | 是否使用及具体分类名称，按实际筛选需要确定 |

### 3.3 产品构成与预计用纸 按真实记录保存

本版用纸口径（2026-10-21用户确定）：材料数量统一按“预计用纸量”录入、统计和导出，不另分预计与实际。由夏填写已知的原材料、预计数量及归属，不要求确认实际耗用后才能录入。

本节产品构成、原材料及预计用纸信息均为选填，保存后可以补充、修改。上版、印法、色别、机印等字段按第3.2节放在各自印刷品下。未填写的数量保留为空，不为了统计而补零。

| 建议字段 | 处理原则 |
|---|---|
| 用纸记录的关联范围 | 每条预计用纸单独多选对应的一项或多项印刷明细；同票内每项明细最多关联一条用纸记录，共用用纸只记一次 |
| 生产构成 | 同一产品可分彩皮、说明、表格等构成，各自填写数量及要求；115的“1＋40”说明内页第一张是说明，另外40张为表格，彩皮另记；构成不能当作额外产品或重复增加本数 |
| 纸张／原材料名称与规格 | 填写实际采用的原材料及规格，暂缺可留空 |
| 预计用纸数量与单位 | 填写预计需要的原材料数量及单位；原纸数量与裁后纸张数、成品数量分别表达，不混用 |
| 共同用纸的适用范围 | 同一记录只算一次；跨学校尚未分清时，保留为共同用纸，不猜分摊比例 |

2026-10-22用户确认：新增的每条预计用纸都有独立的明细多选项。已被其他用纸记录选中的明细不可重复选择，并显示所归属的用纸记录；取消原勾选或移除原用纸记录后，其他记录中恢复可选。关联以明细记录为准，同名产品仍分别识别；增删或改名明细时同步选择项，不影响其他材料填写。用纸及关联仍允许暂空，不要求每项印刷品都填写用纸，也不将该票内录入规则直接推广为跨传票的数据库关系。

**现有 raw 的 `quantity` 应理解为“材料侧数量候选”，不能直接改名为客户订购数量。** 同理，机印张数、成品张数、份数、本数和计费量分别表达不同事情。

095的有效63张原纸、裁后1008张及模板误印／误写说明，继续保留在第七节，作为理解字段的例子；不将旧模板的错误栏名或误写内容带入未来录入表单。

### 3.4 计价与金额

本版计价方式已由用户于2026-10-21确认：正式录入时需要填写单价，各印刷品金额也须有值；单价由录入人填写，不要求从学校价目表自动带出。计价信息足够时金额自动计算，录入人可以修改；数量等选填信息暂缺、无法计算时，可直接填写该项金额，不强迫补齐选填字段或将缺值当零。保存后单价、各印刷品金额仍可修改。整票合计由各项最终保存的金额自动相加，不直接修改整票总额；学校、老师等范围的汇总和导出也采用对应印刷品最终保存的金额。

### 4.2 汇总口径

1. **按订货日期归期。** 2026-10-21用户确认本版按传票订货日期筛选和汇总，导出时写清期间与日期口径。其他日期单独保留，不自动替代订货日期。

3. **数量同口径才相加。** 张、面、份、本、机印数、材料数不混加，规格不同分别列；换算规则未确认时保留原单位。
4. **共同用纸只计一次。** 同校共用且范围和单位已核实，可以在该校材料区记一次；跨校共享未分清时显示未分配记录，不能任意分给学校。
5. **按各印刷品最终金额汇总。** 整票合计自动相加，学校、老师等导出范围只汇总对应印刷品的最终金额，不把整票合计重复计入每项产品，也不将整票合计与各项金额再次相加。
6. **采用已保存的价格与金额。** 正式录入须填写单价、具有各印刷品金额；后续修改保存后，统计和导出采用更新后的金额，不以价格暂空后补作为默认录入方式。
7. **显示统计覆盖范围。** 写清所选期间、学校、组织或老师范围及覆盖的传票；选填数量缺失时保持空白，不能当零，也不能把仅部分有数量的记录称为完整业务量。

| `1＋40` | 描述每本的内页构成，彩皮另记 | 按已确认的张数，说明与表格合计41张内页纸；保留原票表达，纸张数与页／印刷面数分别说明 |

录入要同时表达产品本数、彩皮及内页构成；内页第一张说明和后面40张表格仍属于同一项成册产品，不能因构成有多行重复记录本数或重复计算产品金额。

### 8.2 用户已确认的整本计价

用户确认：7元、6元分别是两种产品的整本单价，均包含彩皮和全部内页。

| 原票产品数量 | 计价单位 | 单价 | 按已确认口径计算的金额 |
|---|---|---|---|
| 140本 | 本 | 7元／本 | 140 × 7 = 980元 |
| 310本 | 本 | 6元／本 | 310 × 6 = 1860元 |

### 8.3 案例使用边界

本例说明成册产品需要表达彩皮与内页构成，并区分本数、内页张数和计费单位。后续只在影响字段设计时继续讨论印面、工艺和用纸，不为本票补齐具体品名、老师姓名或上版数据，也不将“1＋40”推广为其他本册的固定模板。
