# 生产传票录入与导出方案讨论稿

整理日期：2026-10-21；最新修订：2026-10-22。用途：把已经确认的业务规则整理成夏日常录入、修改和导出的具体方案，供继续讨论。本文是需求讨论稿，不是正式规格、数据库设计或开发排期。

规则依据：[生产传票分类与录入导出梳理](生产传票分类与录入导出梳理.md)、[学校与老师CRM梳理](学校与老师CRM梳理.md)及用户最新说明。下文明确区分已确认规则与本次提出的操作建议。

## 一 已确定的使用方式

- 由夏根据实际业务直接在系统录入生产传票，电脑和手机都需要支持。
- 现有已开好的纸票用于分析字段和业务含义，不要求未来先开纸票再录入，也不处理这批历史数据。
- 本期从生产传票开始，不要求先建订单；一张传票可以包含多个印刷品，产品内部还可以有彩皮、内页等构成。
- 保存后可以补充、修改。产品类别、品名、规格、数量及单位、生产与预计用纸等信息本版选填；学校必填，老师缺失允许暂空。
- 单价由夏填写，每个印刷品金额须有值，金额可以自动计算并由夏修改；整票合计自动相加。
- 导出按订货日期选择期间，可以选择学校整体、已有校区／学部等组织范围，或该学校的具体老师。
- 2026-10-22用户确认：删除录入页第一块“基本信息”中的统一学校、老师及默认归属。各印刷品分别选择已有学校和老师；学校、老师档案的增删改查留给后续后台，取消此前随传票新增档案的方式。本轮不实施后台。
- 同日用户进一步确认：上版说明、上版才数、上版次数、印法、色别、机印张数放在各自对应的印刷品明细下，逐项填写，仍为选填、后续可修改。

未来使用主线：直接新建生产传票 → 填写归属和各项印刷品 → 补入已知生产信息 → 保存 → 后续修改、查询及导出。纸票打印要求另行讨论。

## 二 录入信息分成四组

四组表示业务信息的组织方式，不要求分成四个页面。每项印刷品的价格、金额应与对应产品一起填写，避免弄错对应关系。

### 2.1 票级信息：日期与整票说明

页面不再有独立的“基本信息”录入区。以下日期及整票说明保留为紧凑的票级信息，不包含学校、老师或学校组织档案的维护。

| 字段组 | 内容 | 当前规则或建议 |
|---|---|---|
| 传票编号 | 标识系统中的一张生产传票 | 建议由系统生成，具体格式尚未确定；不要求先有纸票号 |
| 订货日期 | 本次业务的订货日期 | 已确定用于筛选、归期和汇总；建议新建时默认当天，夏可以修改，不据此新增必填要求 |
| 取货日期及交期说明 | 已知的取货、送货安排 | 有信息时填写，不替代订货日期 |
| 整票备注 | 其他需要交代的要求 | 选填 |

学校、老师只在各项印刷品明细中选择。档案不存在时，由后续后台维护，录票页不新增、修改或删除档案。老师姓名暂缺时仍允许不选。学校全称、简称归并和“学校＋老师姓名”匹配规则沿用CRM专稿。

### 2.2 印刷品明细：做什么、做多少

每项印刷品单独记录。可以继续添加多项，不给整票强制指定一个产品类别。

| 字段组 | 内容 | 填写要求 |
|---|---|---|
| 该项归属 | 从档案中选择该项学校、该校老师，记录已有校区／学部等业务归属 | 学校必选，老师缺失可暂空，其余选填；用于按学校或老师导出；档案维护在后续后台进行 |
| 产品名称、类别 | 实际品名及需要时使用的类别 | 选填；分类名称仍是建议，不要求先建完整产品目录 |
| 成品规格 | A4等纸型、开本或具体尺寸 | 选填；与原材料规格分别表达 |
| 成品数量、单位 | 例如1000份、100本 | 选填；张、份、本等单位分别保留 |
| 每份纸张数、印面 | 每份包含几张纸，单面、双面或混合要求 | 选填；不能仅因双面就自动把金额乘二 |
| 产品内部构成 | 彩皮、内页第一张说明、其余表格等 | 选填；属于同一产品内部的内容，不重复增加产品本数或金额 |
| 上版说明 | 该项的上版要求 | 选填，按实际要求填写 |
| 上版才数 | 该项的版尺寸／才数 | 选填，保留业务叫法，不预设毫米换算 |
| 上版次数 | 该项的上版次数 | 选填，不由单双面自动推算 |
| 印法 | 该项的印法 | 选填，按实际业务原称填写，不预设与印面同义或固定选项 |
| 色别 | 该项的色别 | 选填，按实际要求填写，不预设颜色或枚举 |
| 机印张数 | 该项的机印量及已知表达 | 选填，与成品数量、原纸数量及计费数量分别表达 |
| 装订要求 | 装订及其他要求 | 选填，按已知信息填写 |
| 明细备注 | 对应这一项的补充说明 | 选填 |

成册产品的表达例子：“100本，每本彩皮另记；内页第一张说明＋40张表格”。产品数量是100本，内页构成为每本41张；不把彩皮、说明、表格再各记成100本独立产品，也不直接将张数换算成页数。

上述六项生产字段在对应印刷品下直接显示并各自记录，取消整票共用工艺输入。填写或修改某项工艺，不自动覆盖其他印刷品，也不直接参与金额计算。

### 2.3 预计用纸：预计用什么纸

本组全部选填，保存后可补充。没有资料时保留为空，不自动补零或推算缺失工艺。

| 字段组 | 内容 | 处理方式 |
|---|---|---|
| 适用范围 | 本条用纸记录对应的印刷明细 | 每条预计用纸独立多选，可关联一项或多项；同票内每项印刷明细最多关联一条预计用纸 |
| 原材料 | 纸张或其他原材料名称、规格 | 原材料尺寸与成品尺寸分别表达 |
| 预计用纸 | 数量及单位 | 本版统一按预计量使用，不要求实际耗用核算 |

2026-10-22用户确认：每次新增预计用纸时，在该条记录内单独选择对应的印刷明细，不再使用整个用纸区共用的一组选项。已被其他用纸记录选中的明细禁用，并注明已关联哪条记录；取消原勾选或移除原用纸记录后恢复可选。新增用纸默认未关联明细，允许暂空，不增加保存门槛。

关联按明细记录区分，同名印刷品仍可分别选择；新增、改名或移除印刷明细时，各用纸记录的选项同步更新，保留仍有效的关联及已填写的材料信息。

例如两项产品共同用一批纸，录一条材料记录并关联这两项，这两项便不能再关联其他用纸记录。汇总时这一条只算一次；按老师导出涉及共享用纸时应说明共享范围，不直接当成某位老师独立使用的纸量。

本稿只整理当前票内的录入关系，不据此确认跨传票共享记录或传票与生产详情的数据库关系。

### 2.4 价格与金额：每项多少钱、整票多少钱

| 字段 | 填写及计算方式 |
|---|---|
| 计费数量、计费单位 | 选填；可以与生产数量使用不同口径，但应分别表达；信息足够时用于计算金额 |
| 单价 | 夏人工填写，必填，保存后可以修改 |
| 印刷品金额 | 信息足够时自动计算，夏可修改；无法计算时直接填写，保存时须有值，后续仍可修改 |
| 整票合计 | 自动相加各印刷品最终保存的金额，不直接修改整票总额 |
| 计价说明 | 选填，需要说明特殊计价时填写 |

自动计算沿用明确的计价单位：按成品纸张计费时用对应纸张数量，按整本计费时用本数；整本单价已包含彩皮和内页时，不再乘内页张数。

操作建议：已由夏修改并保存的金额，不应在修改无关资料时被重新计算覆盖。修改计价相关字段后的金额更新方式在具体交互方案中明确，最终汇总和导出始终取保存后的金额。

## 三 每项印刷品分别选择学校与老师

**本节以2026-10-22用户确认取代旧的票头默认归属建议。**

1. 每项印刷品直接展示学校和老师选择，不再先填一组整票的学校、老师。
2. 新增明细时单独选择归属，不从票头或其他明细自动带入学校、老师。
3. 学校只选已有档案；老师只列出该校已有老师，也可暂不选择。切换学校后重新选择老师，避免保留原学校的老师。
4. 几项明细属于同一学校时，各项可以选择同一学校；这不要求另建一个整票学校字段。
5. 学校、老师档案的新增、修改、删除和查询后续放在后台。录票页只关联档案，不随保存自动新增档案。
6. 导出以各项实际归属为准。产品内部构成和票内共享用纸仍分别记录，避免重复增加产品、金额或材料数量。

本轮只修改演示和需求说明，不开发后台档案管理功能。

## 四 电脑与手机的操作安排

已确定两端都要支持。以下是建议的能力安排，具体网页形态及页面布局尚未确定。

| 操作 | 电脑 | 手机 |
|---|---|---|
| 新建及修改传票 | 支持全部字段、多项印刷品及金额修改 | 同样支持，不只用于查看 |
| 选择学校、老师 | 每项选择已有学校及该校老师；档案维护留给后续后台 | 使用相同选择规则 |
| 补充生产和预计用纸资料 | 在同一张传票上补充 | 能找到同一张传票并补充 |
| 查询和查看 | 按订货日期、学校、老师等查找 | 使用同样的查询口径 |
| 导出 | 按所选范围导出 | 同样能选择范围并取得导出文件 |

建议采用一套适配电脑和手机的网页，两端共用同一份传票数据；不因换设备生成两套独立记录。这是本次方案建议，不代表技术栈、部署环境和页面交付安排已经确定。

## 五 导出先把内容和计算对齐

建议先讨论印刷品明细和学校／组织／老师汇总两种主要输出，生产与预计用纸信息按需要作为附表。原稿的四表工作簿继续保留为组织建议，不要求每次全部导出。建议导出文件采用Excel，具体文件组织和版式待讨论。

| 输出 | 一行表示什么 | 建议内容 |
|---|---|---|
| 印刷品明细 | 一项印刷品 | 订货日期、传票编号、学校、校区／学部、老师、品名、规格、成品数量及单位、计费数量及单位、单价、最终金额、备注 |
| 学校／组织／老师汇总 | 所选范围内同规格、同单位的一组业务 | 期间、所选学校／组织／老师、产品或规格、数量、数量单位、金额；不同单位的数量分开列示 |
| 预计用纸附表 | 一条材料记录及其关联范围 | 传票编号、原材料名称、规格、预计数量及单位、对应产品／共享范围 |

明细和汇总均采用保存后的金额。没有填写的选填资料保持空白，不能写成零；共享材料记录不随产品行展开后重复相加。文件通过传票编号对应系统记录，不要求原图或纸票位置。

### 虚构示例：一票两项，属于不同老师

以下学校、老师、业务及价格均为演示设定，不是现有样票的正式录入结果或学校价目表。假设两项订货日期相同、均落在所选期间，演示编号“示例001”不代表正式编号规则。

| 传票 | 学校 | 老师 | 印刷品 | 成品数量 | 计费数量／单位 | 单价 | 金额 |
|---|---|---|---|---|---|---|---|
| 示例001 | 示例学校甲 | 张老师 | 练习纸 | 1000份，每份1张双面纸 | 1000张成品纸 | 0.10元／张，已含双面 | 100元 |
| 示例001 | 示例学校甲 | 李老师 | 表格册 | 100本 | 100本 | 6元／本，包含彩皮及全部内页 | 600元 |

对应结果：

- 导出学校甲整体：包含两项，金额合计700元；数量分别显示1000份、100本，不能相加成1100份。
- 只导出张老师：包含练习纸这一项，金额100元；不能把整票700元记给张老师。
- 只导出李老师：包含表格册这一项，金额600元；即使每本内页是“1＋40”，也不再用600乘41。
- 夏把练习纸金额改为90元并保存后：整票合计变为690元，学校整体导出690元，张老师导出90元，李老师仍为600元。
- 以后补充某项的用纸资料，只增加对应生产信息，不额外增加该项产品金额。

这是文字示例，尚未生成Excel文件，也未进行任何真实业务结算。
