# 财务与结算｜功能清单与报价草案

> 文档状态：内部评估稿，供逐项与客户讨论；尚非正式报价或已确认需求基线。  
> 整理日期：2026-09-26  
> 报价单元：业务对账、开票与资金往来台账；依赖前四个报价单元及后续交付、库存数据。  
> 金额单位：人民币元。

## 1. 报价目标与业务依据

本单元把总厂传票明细、驻点业务和实际生产量整理为可核对的印刷业务明细，支持学校分阶段对账、按合同登记发票、跟踪回款及往来余额，并记录两家公司各自的业务主体与资金往来。

**本轮“财务”定位为印刷厂业务结算与经营往来台账**：支持会计和商务核对业务、登记发票及收付款、查看应收应付；不等同于完整总账、法定会计报表或税务开票系统。现行“结算单”一词有时指印刷明细／对账材料，尚未证实存在固定格式的独立结算单。因此一期以**对账批次和阶段结算记录**承载业务，不预设必须再造一张独立单据。

已确认的关键事实：

- 会计以“实际干活的印刷明细”与学校先对账，再按合同品项开票。总厂一张传票可涉及多个学校、合同；驻点普通业务又可能没有总厂传票。
- 一个合同可以多次对账、分次开票；一张发票只归属一个合同。学校可能把多个合同的明细一起核对，但开发票时仍按合同区分。
- 实际已经完成约 5 万元业务时，可能先按 7 万元开票或结款，后续继续履约。**已完成业务、已对账、已开票和已收款**须分别记录；先开票不表示已经收到预付款。
- 吉星与津金分别签约、开票、收款，之间可能有借款和还款；实际采购、库存和生产可能共用，内部成本归集口径仍需核对。
- 学校合同外的实际产品可能按合同已有品项折算结算。真实生产内容、计费折算量和折算原因须同时保留。

主要依据：[结算开票流程业务调研](../../02_业务调研/现状业务流程_AS-IS/结算开票流程业务调研.md)、[订单流程业务调研](../../02_业务调研/现状业务流程_AS-IS/订单流程业务调研.md)、[会议5-part2原始记录](../../02_业务调研/沟通记录/会议5/会议5-part2-说话人标注版.md)、[会议5-part3会计访谈](../../02_业务调研/沟通记录/会议5/会议5-part3-说话人标注版.md)、[传票样本核对记录](../../02_业务调研/传票/传票样本核对记录.md)。

## 2. 本轮报价假设

1. 发票功能指**登记、关联和查询已开具发票及凭据**，不直接对接电子税务局或生成具有税务效力的发票。
2. 学校对账日期由经办人选择并可标注采用的业务日期口径；不默认把纸票“订货日期”“取货日期”中的某一个当成全业务统一结算日。
3. 合同价格和基础计价规则复用 B06—B09；本单元处理实际业务明细、折算后计费量、阶段对账、开票与回款，不重复建设合同价格库。
4. 供应商应付、预付及其他费用先支持人工登记。采购、库存与付款形成自动联动的范围，须在库存／采购模块报价时核对。
5. 合同额度联动由本单元维护余额和变动记录：订单、取消和交付模块提供事件；其页面与业务动作仍在各自模块。额度与应收、预收、已开票金额分别保存。
6. 沿用前面报价单元的暂估参数 **300 元／计价工作日**；明细价格按原估人日 ÷ 3 折算计价工作日；目标排期另按 4.8 倍效率测算，见[报价总览](./00_功能选配与报价总览_对客讨论稿.md)。原估人日包含本单元需求细化、页面与接口开发、测试及缺陷修正。

## 5. 与其他报价单元的分工

| 事项 | 归属 |
| --- | --- |
| 公司、学校、合同、合同品项和基础计价规则 | 基础平台与合同计价；本单元引用，不再收取主数据维护费用 |
| 老师下单、申请单照片和订单变更 | 对客下单；本单元引用原始凭据并处理对账差异 |
| 传票明细、票据类型及订单／学校／合同追溯 | 传票；学校印刷收入只从印刷业务明细取数，卖废纸／废品等非订单票经核对后在 F10 单列其他业务收入，物资票不直接算客户收入 |
| 员工报工、实际生产量和驻点完成量 | 生产流程；本单元据此建立“实际干活明细”，不重复记录工序工作量 |
| 包件送达、签收及交付日期 | 交付配送；本单元以其确认结果更新可结算业务和 F15 额度，日期口径需另核 |
| 纸张、油墨、版纸的库存账、采购及实际材料成本 | 库存／采购；本单元登记财务往来或引用成本结果，不重复计算库存数量 |
| 阶段对账、合同开票登记、回款、应收应付、日常收支、其他业务收入及额度账 | 本财务与结算单元 |

**F15 是此前各文档提到的跨模块额度账报价归属。**其他模块负责产生订单、取消和交付事件，不再各自开发一套合同余额。合同剩余额度、已完成业务、已开票、已收款及客户预收余额是不同指标，不能互相替代。

## 6. 建议验收场景

1. 一张总厂传票含两所学校的业务，系统按传票明细和实际产量拆成两份学校业务明细；物资票不进入学校对账。
2. 学校同一学期有两个合同，可以合看业务明细；登记一张发票时只能选择其中一个合同，该合同之后还可再登记其他发票。
3. 实际已完成 5 万元、先开票 7 万元且尚未收款，系统同时显示实际业务 5 万、开票 7 万、待履约差额 2 万及未收款 7 万，不形成虚假的 2 万元生产记录或预收款。
4. 学校先付 3 万元、后续发生并核对 2 万元业务，系统能记录客户预收款及后续抵扣，并保留到账公司和合同边界。
5. 一笔应收分两次回款，能查看两笔到账、已分配金额和剩余应收；未明确归属的整笔回款保留待分配余额，不擅自分摊。
6. 合同外实际制作信封，但按合同品项折算计费；对账记录同时保留信封实际数量、折算品项、计费数量及说明。
7. 津金签约业务由吉星生产，发票和回款归津金；两公司之间的借款另记内部往来，不把生产地点自动当开票公司。
8. 一张卖废纸票记载销售金额后，财务核对实际收款并在 F10 单列其他业务收入；同票若还有复印费，则按各自来源明细分别核对。两项均不进入学校对账，也不会因重复上传传票照片而累计两次。

## 7. 报价前必须核对的资料与问题

| 核对项 | 对范围或价格的影响 |
| --- | --- |
| 一份已完成对账的学校合同及其订单、传票、申请单、实际明细、发票和回款 | 验证 F01—F08 的真实关系，确认是否另有固定格式“结算单” |
| 一笔开票额高于当前实际业务额的记录 | 确认预结差额、后续履约、回款与预收款的实际记账口径 |
| 发票作废／红冲、跨期对账和一笔回款冲多张发票的样本 | 决定 F05、F06 是否需扩大复杂分配和更正流程 |
| 总厂票的订货日期、取货日期与驻点业务记录日期 | 确认筛选对账范围采用哪个业务日期，不能直接沿用票面任一日期 |
| 合同到期仍有已收未干、已干未收或超出合同额的案例 | 确认 F12、F15 的结案和额度处理方式 |
| 吉星与津金各自采购、发票、银行账户和一次相互借款记录 | 确认 F09—F11 的公司归属，避免把共用生产当作共用财务主体 |
| 月度费用表、材料采购与领用样本 | 决定 F10 的费用分类和 F-O02 是否具备可靠成本数据 |

## 8. 报价使用说明

本草案按“原估人日 ÷ 3 × 300 元／计价工作日”估算，可参考国家标准[《软件工程 软件开发成本度量规范》](https://std.samr.gov.cn/gb/search/gbDetailed?id=7E2903B0D6E05A63E05397BE0A0AF660)的成本度量思路；本表尚未完成正式功能点度量。正式商务报价应明确税费、部署环境、第三方税务／银行接口、历史数据迁移、会计口径确认责任及验收范围。
