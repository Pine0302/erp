# 库存与耗材｜功能清单与报价草案

> 文档状态：内部评估稿，供逐项与客户讨论；尚非正式报价或已确认需求基线。  
> 整理日期：2026-09-26  
> 报价单元：总厂至驻点的物料流转、纸张及关键耗材库存、速印机计数和基础差异核查。  
> 金额单位：人民币元。

## 1. 报价目标与业务依据

本单元先解决**总厂和驻点实际有多少纸、油墨、版纸，物料如何补给、签收与耗用，机器实际印了多少，以及差异怎样发现和核查**。一期覆盖外围驻点，并覆盖总厂内部已明确提出的两台速印机的计数和耗材更换记录；不据此推定总厂全部设备、全部原辅料均须实施同等精度的管理。

已知事实和客户诉求：

- 驻点缺料时向总厂提出需求；高老师所在驻点由总厂送来纸、油墨、版纸，使用两联单签收，双方各留一联。总厂四联传票样本也出现物资记录，但目前不能认定它与驻点两联单对应同一笔补料，更不能把两张凭据各记一次库存流转。
- 客户要求一期管理驻点纸张、油墨、版纸等关键耗材，总厂两台速印机也记录每日计数、换墨和换版纸。高老师所在驻点自九月起试用表格登记本站四台机器，不能推定所有驻点已有完整历史台账。
- 纸张主要按“包”交接，但差异核查需要知道开包后的散张。客户已明确 A4 速印纸和 9K 速印纸各为 **2,000 张/包**；其他纸品的包装张数须按物料分别确认。油墨按“支”、版纸按“卷”管理。
- 客户希望每天及更换耗材时记录机器累计计数。相邻两次更换油墨的计数差可表示这一支油墨的**区间印量**，不能直接等同于某一订单的耗墨量。版纸与“过版纸”是不同物料，过版纸属于纸张耗用，需要单独解释。
- 客户提出纸张或印量核对“正常应一张不差，差异预警 ≥3 张，过版纸除外”。差异的比较对象、统计周期、设备范围和正负方向仍需确认；差异先作为待核查事项，不自动定性为损耗。
- 总厂既有按包供纸，也有大张纸经裁切再用于印刷的情形。裁切前后规格、投入与产出数量需要凭现场样本确定，不能只做一次“出库”而失去纸张去向。

主要依据：[外围驻点流程业务调研](../../02_业务调研/现状业务流程_AS-IS/外围驻点流程业务调研.md)、[总厂生产流程调研](../../02_业务调研/现状业务流程_AS-IS/总厂生产流程调研.md)、[会议6驻点访谈](../../02_业务调研/沟通记录/会议6/会议6-驻点高老师-说话人标注版.md)、[会议4原始记录](../../02_业务调研/沟通记录/会议4/会议4-说话人标注版.md)、[传票样本核对记录](../../02_业务调研/传票/传票样本核对记录.md)。

## 2. 本轮报价假设

1. 使用基础平台已建的公司、人员、角色、地点等主数据。库存按**实际存放地点**记数量；采购公司、付款公司、发票公司和物料所有权分别留字段或来源，不预设“吉星和津金共享实物库存”就意味着会计归属相同。
2. 一期管理纸张、油墨、版纸及客户确认的少量同类关键耗材。各物料以基本单位记账，按物料维护包装换算；A4/9K 速印纸的已知换算不套用到所有纸品。
3. 总厂至驻点补料以**一笔调拨、一笔发出、一笔签收**为主线，可关联两联签收单和物资传票照片或编号。凭据的关联不再生成第二次出入库。驻点间调拨、供应商退货等特殊流程在核对后决定是否扩展。
4. 日常出入库先支持人工录入及凭据附件；不含供应商询价、采购审批、采购订单、扫码硬件和机器自动采集接口。
5. 纸张消耗以有据可录的实际领用、退回、散张结存、裁切和报废为基础。订单产量及机器计数仅作为核查来源，不能自动把理论用纸量扣成实际库存。
6. 报修申请为一期简要登记和处理状态；设备保养计划、维修派工、配件成本及师傅绩效单列选配或后续核价。
7. 沿用前五个报价单元的暂估参数 **300 元／计价工作日**；明细价格按原估人日 ÷ 3 折算计价工作日；目标排期另按 4.8 倍效率测算，见[报价总览](./00_功能选配与报价总览_对客讨论稿.md)。原估人日包含本单元需求细化、页面与接口开发、测试及缺陷修正；不是经市场询价确认的报价单价。

## 5. 与其他报价单元的分工

| 事项 | 归属 |
| --- | --- |
| 员工账号、权限、公司及地点基础信息 | 基础平台与合同计价；本单元引用并增加物料及库存地点属性 |
| 客户订单、申请单、订单变更 | 对客下单；本单元只引用订单及生产来源，不维护客户下单表单 |
| 总厂生产传票和物资票类型、票面打印及签发 | 传票；本单元引用物资票作库存凭据，不把客户生产票自动当作补料单 |
| 任务、机台关联、报工及实际产量 | 生产流程；本单元保存机器累计计数、耗材领用与核对结果 |
| 供应商应付、付款、费用、客户应收及利润展示 | 财务与结算；本单元提供物料数量及经确认的材料成本来源，不重复建往来账 |
| 成品包件、送校、签收 | 交付配送单元；总厂给驻点送原材料是本单元的物资调拨，不作为客户订单交付 |

**数量口径要分清：**“已申请补料”“总厂已发出”“驻点已签收”“已领用”“实际消耗”“盘点余量”是不同事件。机器累计计数、订单/生产数量和库存数量只有统一期间、地点、机台及张/面等口径后才可比较。

## 6. 建议验收场景

1. 总厂为驻点发出 A4 速印纸 5 包，驻点实际签收 4 包并说明少收 1 包；系统显示总厂已发、驻点实收及待核差异，两联单和物资票若均上传只形成一次调拨。
2. 驻点将 1 包 A4 速印纸开包，实际只用 120 张；库存能反映剩余散张，不能把开包当作一次耗尽 2,000 张。9K 纸也按单独物料维护 2,000 张/包，复印纸不得被默认套用该换算。
3. 总厂一批大张纸裁切成另一规格纸，系统保留投入数量、裁切后可用数量及边料/废张原因，成品规格库存增加且原纸库存相应减少。
4. 一台驻点速印机连续两次换墨，分别记录累计计数 100,000 和 106,000；显示上一支墨的区间印量 6,000。计数倒退或跨机记录被标为异常，不直接作为每单耗墨量。
5. 同一天机台产量、生产任务和纸张耗用存在差异，系统列出过版、试印、补印及未解释部分。对可比张数达到约定阈值时提示核查；1—2 张差异仍可查看，不因低于阈值而消失。
6. 总厂两台速印机可分别记录每日计数、换墨及换版纸；其他总厂设备若未在确认清单中，不要求凭空录入全部历史数据。
7. 驻点提交机器报修申请后，机台只显示“待处理/处理中”等记录；维修人员登记恢复结果后才显示已处理，不因提交申请自动变成修复。

## 7. 报价前必须核对的资料与问题

| 核对项 | 对范围或价格的影响 |
| --- | --- |
| 各驻点、总厂库存地点和机台清单，以及本期必须覆盖的物料 SKU 与历史期初数 | 决定 I01— I03、I10 的实际数据准备量；当前只有个别驻点机器实例 |
| 同一笔补料的申请、总厂物资票（若有）、两联签收单、实际收货和退回样本 | 核实 I04— I06 的单据关系、签收差异、是否需要分批发放及避免重复记账 |
| 纸张各规格每包张数、开包余纸的实际记法、裁切前后规格和投入产出样本 | 决定 I01、I08、I09 能否做到真实数量核对；A4/9K 速印纸 2,000 张/包不能外推 |
| 各机器计数器含义、换表/清零情形、日读数时间点和补录规则 | 决定 I10、I11、I13 的有效区间与差异可比性 |
| 一笔含过版、试印、废张或返工的订单，及对应机台计数、用纸和库存记录 | 确认三账核对换算方式及未解释差异的来源，避免把差异自动当作损耗 |
| “≥3 张”比较哪两种数量、按单还是按日/机台、正负差异是否均预警、过版纸如何扣除 | 决定 I13 规则配置和验收口径；油墨“支”及版纸“卷”不适用纸张阈值 |
| 吉星、津金各自采购、付款、发票和共同使用材料的实例 | 决定 I02、I15 与 I-O02 的公司归属和成本口径，不由共享库位推断财务归属 |
| 一笔设备报修及维修完成凭据 | 核实 I16 的最小状态和处理人；复杂维修流程及费用如需要再选 I-O04 |

## 8. 报价使用说明

本草案按“原估人日 ÷ 3 × 300 元／计价工作日”暂估。可参考国家标准[《软件工程 软件开发成本度量规范》GB/T 36964-2018](https://std.samr.gov.cn/gb/search/gbDetailed?id=7E2903B0D6E05A63E05397BE0A0AF660)的成本度量思路；本表未完成正式功能点规模测量，**不能称为依据该标准算出的正式报价**。正式商务报价应在上述样本和规则确认后明确税费、部署环境、历史数据迁移、首期物料与机台范围、第三方接口及验收边界。
