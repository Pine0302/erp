# 生产流程｜功能清单与报价草案

> 文档状态：内部评估稿，供逐项与客户讨论；尚非正式报价或已确认需求基线。  
> 整理日期：2026-09-26  
> 报价单元：总厂与驻点生产流程；依赖[基础平台与合同计价](./01_基础平台与合同计价_功能清单与报价草案.md)、[对客下单](./02_对客下单_功能清单与报价草案.md)和[传票](./03_传票_功能清单与报价草案.md)。  
> 金额单位：人民币元。

## 1. 报价目标与业务依据

本单元把已签发的总厂生产传票明细或驻点普通订单转成可执行任务，记录工序、执行地点、人员、实际完成量和异常，并支持总厂与驻点共同完成一笔业务。生产记录应能提供给后续交付、库存和财务使用，但不直接生成发票或工资。

已知业务事实与需要保留的差别：

- 不同产品经过不同工序；同一张传票内的产品也可能有不同加工要求。不能把整票强制套用一条工艺路线。
- 几乎所有工序都可能由多人分担或前后接替。**计划分工、实际完成量、实际发生时间和补录时间**应分开。
- 1000 册装订完成 300 册时，这 300 册可以先进入打包、运输或交付；局部完成不代表整单完成。
- 驻点普通业务可自行生产，不经过总厂生产传票。需要总厂协作时可全部转总厂、按工序或数量分担、按产品分担；总厂也可授权驻点生产其他学校的业务。
- 总厂生产经理负责协调生产和驻点协同。客户已要求未来先认领任务，但现状是否已有统一认领登记制度仍未核实。

主要依据：[总厂生产流程调研](../../02_业务调研/现状业务流程_AS-IS/总厂生产流程调研.md)、[外围驻点流程业务调研](../../02_业务调研/现状业务流程_AS-IS/外围驻点流程业务调研.md)、[订单流程业务调研](../../02_业务调研/现状业务流程_AS-IS/订单流程业务调研.md)、[会议5-part1原始记录](../../02_业务调研/沟通记录/会议5/会议5-part1-说话人标注版.md)、[会议5-part2原始记录](../../02_业务调研/沟通记录/会议5/会议5-part2-说话人标注版.md)、[会议6驻点访谈](../../02_业务调研/沟通记录/会议6/会议6-驻点高老师-说话人标注版.md)。

## 2. 本轮报价假设

1. 一期围绕已取得样本中的主要产品与工序建立工序字典和可调整模板；完整工序清单、每道工序的工作量单位及现场终端仍需由生产经理核对。
2. 总厂任务从**传票明细**形成，驻点普通任务从**驻点订单**形成。票号不是唯一生产任务号，多个地点或工序可对应同一客户业务；每项客户需求仍保留原学校和合同归属。
3. 员工通过手机浏览器或车间电脑认领、报工；总厂可扫描传票 T12 的条码进入对应工序，再由已登录员工确认认领和报工，不能仅凭扫码自动记完成量。无扫描枪时仍可按任务查找操作。基础平台 B03 的账号与角色权限、传票 T10 的交接数据直接复用；驻点普通业务不强制使用总厂传票扫码流程。
4. 本单元记录实际生产量和基本异常；包装包件、配送照片、签收及学校交付状态由后续交付单元承担。机器累计计数、油墨／版纸更换、纸张库存及三账核对在库存与设备相关单元报价。
5. 沿用前面报价单元的暂估参数 **300 元／计价工作日**；明细价格按原估人日 ÷ 3 折算计价工作日；目标排期另按 4.8 倍效率测算，见[报价总览](./00_功能选配与报价总览_对客讨论稿.md)。原估人日包含本单元需求细化、页面与接口开发、测试及缺陷修正。

## 5. 与其他报价单元的分工

| 事项 | 归属 |
| --- | --- |
| 学校、员工账号、岗位权限基础 | 基础平台与合同计价；生产模块只配置工序可认领范围 |
| 客户需求、驻点快速代录、订单修改请求 | 对客下单；生产模块接收订单及经批准的变更结果 |
| 多学校／多品项传票、票据签发、打印及条码生成 | 传票；生产模块从传票明细生成任务，不重复建设传票编辑 |
| 工序、任务、排产、扫码进入工序、认领、报工、部分流转、地点协同 | 本生产流程单元 |
| 包件、配送、签收、送达照片、部分交付的客户凭据 | 交付配送单元；本单元提供可交付数量 |
| 纸张、油墨、版纸出入库，设备累计计数、耗材更换及三账差异核查 | 库存与设备记录单元；P11 只记录生产任务与机台的关系及本任务产量 |
| 合同计费量、实际业务明细、应收、开票、回款及工资绩效金额 | 财务／绩效单元；P05、P13 提供实际工作量来源 |

驻点完成一部分、总厂再加工同一批产品时，两个地点的**工序工作量可分别记录，客户订购数量不能重复相加**。总厂将其他学校业务交给驻点生产时，生产地点变化也不得改写原学校、老师和合同归属。

## 6. 建议验收场景

1. 一张传票有两个产品且工序不同，系统按传票明细分别形成任务；员工只看到其有权执行的工序。
2. 1000 册装订任务由 A 做 300 册、B 做 300 册、C 做 400 册，三人的实际工作量可分别查看，总完成量为 1000 册。
3. A 中途离开先登记已完成量，B 接替；系统保留两人的记录及实际发生、补录时间。
4. 装订先完成 300 册，这 300 册可进入后续加工／交付准备，其余 700 册仍在制；订单不被误判为全部完成。
5. 驻点印 600、总厂印 400，再由总厂装订 1000；生产地点和工序工作量分别记录，客户订购量仍为 1000。
6. 生产经理把其他学校业务授权给一个驻点完成，生产记录显示该驻点，业务仍归原学校及合同。
7. 驻点普通试卷生产后，总厂能查看实际产量，但系统不要求补造一张总厂生产传票。
8. 总厂工人扫描样稿条码后看到正确工序；A 登录并认领、登记已完成数量后，B 不能代替 A 无痕确认，B 接替时另记本人工作量。

## 7. 报价前必须核对的资料与问题

| 核对项 | 对范围或价格的影响 |
| --- | --- |
| 主要产品、完整常用工序和各工序工作量单位 | 确认 P01、P05 的模板数量与报工口径；示例路线不能当完整清单 |
| 一笔多人接替及一笔部分完成先流转的真实业务 | 确认任务划分、数量校验、补录和完成判定 |
| 一笔驻点转总厂、一笔双方按数量分担的现场单据 | 确认 P09、P10 的审批、半成品交接及汇合关系 |
| 生产经理对加急、换人、换地点、改数量的处理方式 | 确认 P03、P06、P09 的授权与变更规则 |
| 一笔错印、废品或返工案例 | 确定 P12 的最低字段，以及是否需要 P-O02 的完整质检流程 |
| 机台、生产数量、机器计数和过版纸的实际记录样本 | 确认 P11 与后续库存／设备记录单元的接口和单位，避免把机印数直接当成成品数 |
| 总厂、驻点可用的电脑、手机、网络及普通扫描枪 | 确认现场操作方式及 P15 的硬件前提；驻点普通订单不强制配置扫描枪 |

## 8. 报价使用说明

本草案按“原估人日 ÷ 3 × 300 元／计价工作日”估算，可参考国家标准[《软件工程 软件开发成本度量规范》](https://std.samr.gov.cn/gb/search/gbDetailed?id=7E2903B0D6E05A63E05397BE0A0AF660)的成本度量思路；本表尚未完成正式功能点度量。正式报价应明确税费、设备和网络条件、数据迁移、跨模块验收及变更处理。
