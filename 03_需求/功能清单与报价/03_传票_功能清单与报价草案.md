# 传票｜功能清单与报价草案

> 文档状态：内部评估稿，供逐项与客户讨论；尚非正式报价或已确认需求基线。  
> 整理日期：2026-09-26  
> 报价单元：传票；依赖[基础平台与合同计价](./01_基础平台与合同计价_功能清单与报价草案.md)及[对客下单](./02_对客下单_功能清单与报价草案.md)。  
> 金额单位：人民币元。

## 1. 报价目标与业务依据

本单元将总厂按流水号流转的各类传票电子化。印刷传票把客户需求转成车间可执行的生产依据，其他传票记录物资、采购、加工或收入事项，并按明细交给相应模块处理。**订单、传票、传票明细和生产任务是不同对象**：一张传票可汇集多个品项、订单，偶尔包含多个学校；一笔订单也可能按实际分工拆到多张传票或任务。是否允许一笔订单拆多张传票仍需样本验证，本报价按支持分拆的数据关系预留。

现状与样本要点：

- 总厂现用四联《吉星印刷厂作业传票》。生产经理手写生产要求，纸质稿和电子稿进入车间时均有传票随工流转。电子草稿、审核和状态流转属于拟建系统能力。
- 夏经理说明一张传票可有多个产品，也可能汇集不同学校/单位的相近业务；票内不同产品的工序要求可能不同。传票票头的订货单位不能覆盖每一行的真实归属。
- [票号 0000465](../../02_业务调研/传票/微信图片_20260919115402_6_2999.jpg) 可见同票多品项及手写计价算式；[0000472](../../02_业务调研/传票/微信图片_20260919115403_7_2999.jpg)、[0000474](../../02_业务调研/传票/微信图片_20260919115405_8_2999.jpg) 使用同样的四联票记载驻点物资。票面手写金额是否为最终结算金额尚未证实。
- [首次访谈](../../02_业务调研/沟通记录/访谈记录1-2026-08.md)说明一个月的传票流水混有不同学校印刷、卖废纸、切纸和进货；[会议1](../../02_业务调研/沟通记录/会议1/会议1-说话人标注版.md)说明向外围发物资、卖废纸收入也写传票；[会议5](../../02_业务调研/沟通记录/会议5/会议5-part1-说话人标注版.md)还确认个体印刷、阶段汇总的复印费和外包加工事项。外包需保留传票记录，完整供应商交接流程另见生产增强项。
- 驻点自行完成的普通印刷业务通常没有总厂生产传票；驻点需总厂加工时，总厂承担的部分才进入传票流程。驻点签收补料所用两联单与总厂四联票的关系尚待核对。

主要依据：[订单流程业务调研](../../02_业务调研/现状业务流程_AS-IS/订单流程业务调研.md)、[总厂生产流程调研](../../02_业务调研/现状业务流程_AS-IS/总厂生产流程调研.md)、[外围驻点流程业务调研](../../02_业务调研/现状业务流程_AS-IS/外围驻点流程业务调研.md)、[传票样本核对记录](../../02_业务调研/传票/传票样本核对记录.md)、[会议5-part2原始记录](../../02_业务调研/沟通记录/会议5/会议5-part2-说话人标注版.md)。

## 2. 本轮报价假设

1. **传票不是订单，也不限定为废纸出售或印刷生产。**一期必做范围包括学校／石化／个体印刷、驻点物资往来、废纸／废品出售、进货、切纸加工、阶段汇总的复印费及外包加工的传票登记；同一票号可有不同用途的明细，不能只按整票归类。一张印刷传票可承接多个订单、学校和品项。各用途的后续动作分别由生产、库存或财务模块承担，非印刷明细不生成学校生产任务或应收。
2. 一期提供一套按真实样本校对后的基础传票版式，并提供可贴在样稿上的普通打印条码标签版式；支持标示四联用途。专用热敏标签打印机适配、特殊纸张、复杂套打设备和多套自定义版式另估。
3. 传票保留生产计划数量、材料要求和工艺要求；实际耗用、工序完成量、员工报工及排产由生产／库存模块记录。
4. 金额或手写算式可作为内部备注或待核对信息保存；生产打印默认不展示合同价格，也不把票面金额直接计入应收。财务按**每条印刷业务明细**核算。
5. 沿用前两个报价单元的暂估参数 **300 元／计价工作日**；明细价格按原估人日 ÷ 3 折算计价工作日；目标排期另按 4.8 倍效率测算，见[报价总览](./00_功能选配与报价总览_对客讨论稿.md)。原估人日包含本单元需求细化、页面与接口开发、测试及缺陷修正。

### 一期必须支持的传票业务场景

下表各项的传票建票和登记均属于上述必选功能；需要生产、库存或财务后续处理的，按对应基础模块交接。外包供应商完整协同另见 P-O03；实际字段和金额含义在实施时对照原票确认。

| 票种／场景 | 一期传票侧处理 | 下游归属与边界 |
| --- | --- | --- |
| 学校、石化等客户的印刷加工 | 可一票多订单、多学校、多品项；逐明细保留来源、数量、工艺和实际生产去向 | 生产按明细生成任务，财务按学校、合同及业务明细核算；票头金额不直接作应收 |
| 个体客户印刷加工 | 不要求学校合同；登记客户、品项、数量、工艺、交付及票面金额来源，可走总厂生产传票 | 生产按明细执行，收入与收款由财务按对应客户核对；零散复印费另按期间汇总 |
| 总厂向驻点发纸张、油墨、版纸等物资 | 非客户订单票，登记物料、数量、地点及凭据；不把每次印刷的油墨消耗误作独立物资传票 | 库存模块办理发出与签收；传票和驻点两联签收单是否指同一事件须核对，同一调拨不重复增减库存 |
| 卖废纸／废品 | 可独立建票，也可与复印费等不同性质业务同票；逐明细登记出售对象、品类、重量／数量、单位、单价、金额及原票附件 | 财务 F10 按来源明细核对销售金额与实际收款，单列其他业务收入；不计入学校印刷收入。同票其他明细分别处理，废品来源及库存扣减规则仍需实票确认 |
| 进货／采购 | 可登记供应商、物料、数量、票面金额及原票凭据 | 库存 I03/I15 及财务 F09 分别处理实物入库与应付；传票本身不自动完成入库或付款 |
| 切纸／独立加工 | 区分订单内的生产工序与独立收费业务，保留来源、数量及说明 | 订单内加工进入生产；独立收费可由财务登记其他业务收入。独立加工的专属报工及成本流程待样本确认 |
| 零散复印费汇总 | 可单独成票或与废纸等业务同票登记复印费明细，保存期间、金额及来源说明，不要求每笔零散交易都开一张传票 | 财务 F10 按来源明细单列收入；逐笔收据和收银能力见财务选配 F-O01，同一笔业务不能重复计入收入 |
| 客户订单中的外包加工或外采成品 | 基础传票登记外包事项、承接方、品项、数量、金额来源及与客户订单的关系；标明由外部加工，避免误按本厂工序派工 | 回厂后加工、打包或交付按实际去向处理；供应商交接、外包完成量及回厂接收的完整协同见生产选配 P-O03 |
| 未识别的其他票 | 保留原票照片、用途、说明和待核对状态，不自动归入印刷生产 | 新的专属票种流程须取得样本后另行核价 |

以上各已知场景的**传票建票、逐明细登记、查找和基本分流均为必做**；完整外包协同、专属审批、自动记账、库存扣减或会计凭证处理依照对应模块范围。现有照片还可见 0000486 同票记录“废纸”和“复印费”、0000487 记录“刀切纸”；废纸是否出售、切纸是否独立收费，以及进货、零散复印汇总等具体流程仍需实票和经办人核对。

## 5. 与其他报价单元的分工

| 事项 | 归属 |
| --- | --- |
| 公司、学校、合同、产品价格、账号权限 | 基础平台与合同计价；传票只引用，不重复报价 |
| 老师下单、商务或驻点代录、学校申请单及订单变更请求 | 对客下单；传票可引用客户订单，也承接总厂物资、采购、废品收入等非订单业务 |
| 一票多明细、票据分类、生产要求、签发、打印及扫码查票 | 本传票单元 |
| 工艺模板维护、排产、工序任务、扫码认领、报工、实际完成量及质量追溯 | 生产流程模块；传票只提供计划与要求 |
| 物资票对应的正式出入库、总厂到驻点调拨、驻点签收及库存账 | 库存模块；T04 仅负责识别、登记与关联入口 |
| 实际干活明细、合同折算、对账、发票、回款及票面金额解释 | 财务模块；T11 只提供可追溯的来源关系 |

不得把一张混有多个学校的传票按票头汇总给单一学校，也不得把物资票视作客户印刷收入。纸票与订单的对应关系必须落实到**传票明细**，财务金额以经核对的业务明细和合同规则为准。

## 6. 建议验收场景

1. 生产经理把两所学校的相近印刷任务写入一张电子传票，每条明细仍能回到各自订单、学校和合同；财务按学校分别取数。
2. 一张传票有试卷和答题卡，装订要求不同，车间能按明细看到不同生产要求。
3. 纸稿订单生成传票时可关联实物交接说明，无须先扫描纸稿；电子稿可从票内找到。
4. 一张记载驻点纸张和油墨的四联票被登记为物资用途，不进入学校印刷对账；库存调拨由库存模块处理。
5. 已签发传票修改后能追溯改前、改后内容和操作人，已下发的生产任务收到变更提示。
6. 同一旧纸票拍摄两张照片，仍按同一票号索引；旧纸票号不会被当作两笔新业务。
7. 一张传票含不同生产明细时，各样稿标签能准确打开对应明细及生产要求；工人也可扫描纸质传票上的条码或按票号查找，不会把样稿错配到另一学校或订单。
8. 一张卖废纸票可在无学校订单时录入出售对象、重量／数量、单价、金额和原始凭据，供财务核对销售与收款并单列其他收入；它不会生成学校生产任务或合同应收，库存扣减仍按确认后的实物流转规则处理。
9. 一张含两所学校订单且工序不同的票，生产按明细分别安排，财务按来源分别对账，票头相同不会混并学校收入。
10. 一张票同时记有废纸出售与复印费，系统按明细保存各自用途和金额；财务分别核对并只计入一次，不将整票归为印刷订单。
11. 个体客户印宣传单可开总厂生产传票并记录实际业务与收款来源，无需虚构学校和合同；零散复印费可隔一段时间汇总成票。
12. 一张进货票登记供应商、物料和数量后关联库存入库与应付；一张外包加工票记录承接方及需本厂继续完成的环节，纯外包部分不误派本厂机台任务。
13. 单独切纸收费与印刷订单内部切纸工序分别登记，财务只对独立收费明细核对其他业务收入。
