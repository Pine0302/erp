## 第一部分：下单流程逻辑

### 1.1 通用 4 阶段模型

**所有 61 个商品** 都遵循同一套 4 阶段流程：

```
┌─────────────────────────────────────────────────────────┐
│  ① 选规格 → ② 计算价格 → ③ 上传文件 → ④ 提交订单          │
└─────────────────────────────────────────────────────────┘
```

页面结构都是单页表单，4 个按钮：「取消」「保存」「计算价格」「上传文件」。

### 1.6 流程联动规则（基于页面观察）

虽然脚本未触发实际联动（只看不操作），从 DOM 结构推断：

1. **材料选择后联动工艺选项**：例如画册选了"内页材料"才显示对应"内页工艺"
2. **数量档位变化触发价格档位重算**：选择不同数量（200/500/1000）显示对应价格表
3. **多选工艺合并到总价**：工艺选项（打孔、圆角、压点线等）每个单独计费，叠加到基础价格
4. **款数联动价格**：款数 > 1 时价格通常上浮

> ⚠ 联动规则的**精确数值**需要实际选规格+点击「计算价格」才能验证。本报告只展示静态结构。

### 1.7 关键页面提示（来自 61 个商品页面文本）

各商品类别的"红字提示"通常出现在顶部，是**该品类的强制要求**：

| 类别 | 提示 |
|---|---|
| 名片 | 大面积底色、一面重色一面浅色**必选覆膜**；压痕**必选覆膜**；异形转单页 |
| PVC 名片 | 黑色底/字/码**必须设计单黑** |
| 画册 | 平网、大面积重底色价格上浮 10%（起价 300 元） |
| 刮刮卡 | 可变数据字体大小随机调整，需提前告知客户 |
| 便利贴 | 可变数据字体大小根据数据长短自动调整 |
| 宣传单/单页 | 距成品边至少 3mm（含出血四周各 2mm）；尺寸输入为**不含出血** |
