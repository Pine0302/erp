## 2. 业务现状概述

总厂接收印刷需求和稿件，以生产传票承载生产信息，组织员工完成相应加工、打包及交付，并记录员工实际工作量供后续统计。

当前明确存在以下情况：
1. 业务入口包括电子稿、纸质稿及驻点协作任务。
2. 总厂生产依赖四联无碳复写纸质生产传票，保存和查询较为困难。
3. 工序、执行人员和实际工作量主要依靠人工记录，月底需要翻查传票统计员工工作量。
4. 不同产品经过不同工序，不能用一条固定工艺覆盖全部业务。
5. 员工存在一人多岗，同一道工序可能由多人分担或前后接替。
6. 部分数量完成后可以进入后续工序，甚至先行打包和送货。
7. 一张订单经常拆成多个包件，包装信息存在人工手写情况。
8. 总厂与外围驻点之间存在按工序、数量或产品分工的协作。
9. 纸质传票既可列多个产品，也可汇集不同学校/单位、相近规格的多笔业务；票内产品的工序可能不同，生产经理以手写明细说明。不能按“一张订单＝一张传票＝一个产品＝一个学校”还原现状。[会议5-part2-0234—0250、0258—0298]
10. 夏经理说明目前主要把生产要求写在传票上，没有另设独立排产台账；第一轮留存的《印刷生产台账》样本究竟在哪些业务、岗位或时期使用，需另行核对。[会议5-part1-0344]

上述特点意味着：不能将现状理解成“每道工序固定由一人做完，整单才能进入下一步”。

## 4. 生产任务的入口与组织方式

### 4.1 直接进入总厂

总厂业务存在电子稿和纸质稿两类入口。纸质稿可以由司机带回总厂，电子稿对应电子内容及客户提出的印刷要求。

在理解入口时，应区分：

- **稿件**：要印刷的具体内容。
- **印刷要求**：数量、规格、用纸、装订、交货时间等。
- **生产传票**：承载生产信息、参与内部生产流转和工作量统计的单据。

收到稿件不一定等于已经具备全部生产条件。现有业务由谁补齐要求、谁开传票、交给谁安排生产，本稿暂不补写为确定流程。

### 4.2 驻点整体转总厂

驻点无法完成的复杂产品可以全部转总厂生产。

客户已确认：驻点申请总厂协同需要生产经理审批，由生产经理决定生产安排。具体审批目前采用何种方式，文档未展开。

### 4.3 驻点与总厂共同完成

双方可以分别完成不同工序、不同数量或不同产品。

### 4.4 总厂安排驻点生产

客户补充：总厂有权安排驻点完成总厂需要印刷的业务，即使这部分业务不属于驻点绑定的学校。
因此，协同关系包含驻点向总厂提出需求，也包含总厂向驻点分配任务。

### 5.1 生产传票

现有四联纸质传票是总厂生产的重要单据，也承载了后续人工统计所需的信息。传票数量大，保存、查询和月底翻查的成本较高。

纸稿、电子稿进入总厂车间后均随纸质传票流转。生产经理会把多个产品写在一张票上，偶尔汇集不同学校的相近业务；若产品需要不同工序，则在票面手写说明。票号和票头不能直接替代每项业务的学校、产品、实际生产与结算归属。[会议5-part2-0135、0234—0250、0258—0298]

原文列出的订单、材料要求、生产数量、工艺路线、创建人、审核人、版本等，是未来电子传票的数据建议，不能直接当作当前纸质传票的实有字段。

**小丽核实稿件和商务要求 → 生产经理转为生产要求并手写传票 → 传票与样稿夹在一起、统一摆放 → 师傅取稿并按传票加工。**

同时补齐了：

- **四联分工**：生产经理、财务、生产车间、库管各留一联。
- **实际纸质字段**：根据照片记录，和未来电子传票字段分开。
- **重复录入**：商务先写、开传票再写、结算时重新录入电脑。
- **混合业务传票**：还包括卖废纸、切刀、进货等，不能把全部传票都当作印刷订单。
- **电子化的关键目的**：减少重复填写，同时保持实物样稿与生产要求准确对应。

本批实物照片进一步证实：[票号 0000465](../传票/微信图片_20260919115402_6_2999.jpg) 一票多品项且手写计价算式，[0000472](../传票/微信图片_20260919115403_7_2999.jpg)、[0000474](../传票/微信图片_20260919115405_8_2999.jpg) 则用相同四联票记录给驻点的物资。印制的金额格可空着，算式另写在空白处；表格有订货日期和取货日期，但实填情况不一。不能仅凭票号或表头判断业务类型、金额和日期。详见[传票样本核对记录](../传票/传票样本核对记录.md)。下一步需将一张票的各联、对应实物及会计录入记录串起来核对。

### 5.2 产品与工艺路线

原文提供以下示例：

| 产品类型 | 工艺路线示例 |
| --- | --- |
| 试卷 | 速印 → 打包 → 配送 |
| 成册产品 | 备料 → 切纸 → 胶印 → 刷胶 → 贴封皮 → 成品裁切 → 打包 → 配送 |

以上用于说明路线差异，并非总厂完整的产品与工艺清单。原文其他位置还出现装订等工序名称，暂不将各处示例拼成一套强制标准路线。

王姐补充常见的试卷路径为印刷、裁切、打包、交付；成册或需装订的业务会在印后增加装订，再进行后续裁切/包装。具体先后仍随产品和票面要求变化，不采用固定数值判断全部工艺。[会议5-part1-0111—0124]

会议4现场展示了两种进纸形态：已裁成规格并按包交付的纸，以及仍需按成品尺寸上切刀裁切的大张纸。复印、速印、胶印会按批量和设备条件选择；访谈中的“几十张”“上千张”是现场举例，不是固定分机阈值。部分设备开印前会用旧纸作“过版纸”，不同设备做法不同；过版纸与成品张数、版纸耗用要分开记录，不能将示例“三到五张”定成统一损耗标准。[会议4-0038—0046、0091—0108、0122—0134]

客户要求未来可调整、保存、删除和命名工艺模板。这反映了业务需要灵活配置路线，但现状中具体如何确定和调整路线仍需补充。

### 5.3 打包与交付

文档明确一张订单经常拆成多个包件，包件数量取决于实际印刷量；当前存在学校、老师、产品等包装信息的人工填写工作。

学校送达现场可能出现老师不在、学生代取、门卫代收或材料临时放置等情况。客户要求未来送达照片覆盖全部包件并拍到标签，送达地点文字“最好有”。这些属于交付凭据的拟建要求，不能推断目前已有同样制度。


## 6. 工序执行中的主要业务特点

### 6.1 一人多岗与多人完成

客户明确反馈，几乎所有工序都可能发生多人协作。不能继续将胶印、打包、配送一律定义为只能一人完成。

多人完成至少包括两种情况：

| 情形 | 业务含义 | 原文示例或说明 |
| --- | --- | --- |
| 分担数量 | 多名员工分别完成同一工序的部分数量 | 1000册装订由A完成300、B完成300、C完成400 |
| 前后接替 | 一人中途离开，其他员工继续其未完成部分 | 员工操作速印机时被安排做其他工作，由另一人接替 |

以上不代表多人同时操作同一台机器。现状允许多人完成，与具体岗位、设备能否同时操作是不同问题。

### 6.2 计划分工与实际完成量可能不同

员工可能在生产途中被调去处理更紧急的任务，由其他人完成原先分配的剩余部分。

客户还描述了两种记录时机：离开前先记录已完成量，或回来后再补录。因此，现场生产进度与记录时间可能不完全同步。

==客户确认未来需要“先认领”，但当前是否已有固定的认领登记制度、怎样登记，并未明确。==

==整理业务时应保留以下区别：==

- ==原先准备由谁完成多少；==
- ==最终每个人实际完成多少；==
- ==实际生产发生时间与记录补登时间。==

### 6.3 部分完成即可向后流转

客户明确举例：1000册中装订完成300册，可以先打包、运输和送货这300册。

因此，同一订单在同一时刻可能有部分仍在加工、部分已打包、部分已送达。部分送达不等于整单完成。

现阶段记录“允许分批流转和分批交付”这一业务事实。批次编号、数量校验、完成状态等系统细节留待设计。

### 6.4 工作量与质量追溯

当前员工工作量主要依赖人工记录和月底翻查传票。原文中的工作量示例包括胶印“转”、装订“册”，说明不同工序可能采用不同统计单位；完整单位口径尚未形成。

客户希望未来记录开始、完成时间，并能追溯出错的订单、工序、人员和具体事件，支持质量评价及培训改进。现有质量检查、返工、责任认定的实际流程尚缺少说明。

来源：原文第7.10—7.13节、待确认问题第10—12项。

## 7. 总厂与外围驻点协同

| 协同方式       | 业务示例                         | 分工依据         |
| ---------- | ---------------------------- | ------------ |
| 全部转总厂      | 驻点无法完成的复杂产品转总厂生产             | 生产能力及产品要求    |
| 驻点印刷、总厂后加工 | 驻点印刷 → 总厂装订 → 配送             | 工序           |
| 双方分担数量后汇合  | 1000册中驻点印600、总厂印400，总厂装订1000 | 数量，并在后加工阶段汇合 |
| 不同产品分别生产   | 同一次考试，试卷由驻点做、答题卡由总厂做         | 产品           |
| 总厂向驻点分配任务  | 驻点承接总厂安排的非绑定学校业务             | 总厂统一安排       |

客户反馈规则：

- 涉及双方协作，由总厂生产经理统一协调。
- 驻点申请总厂协同，需要生产经理审批。
- 生产经理决定全部转总厂、双方各做一部分或总厂负责后加工等安排。

上述例子说明客户业务与内部生产执行不能简单等同。一个客户订单可能需要多个生产任务共同完成，但当前纸质传票如何对应这些任务，尚未明确。

| 质量问题 | 客户希望追溯到工序、人员和事件 | 记录诉求，现有检查及返工流程待补充 |
| 速印机与耗材 | 总厂有2台速印机，客户要求记录纸张、油墨、版纸及设备计数 | 记录生产配套管理需求；不推断已有完整库存制度 |
| 设备维修 | 客户提出维修记录、维修及配件费用、维修人员绩效等诉求 | 保留需求，不写成现有流程 |
| 库存补充与设备报修 | 客户要求总厂及驻点速印机具备相关申请记录 | 具体流程及一期范围另行确认 |
| 成本统计 | 文末反馈订单按原材料成本计算，人工等费用在月财报汇总 | 保留客户反馈，成本模块另行统一口径 |

原文驻点计数反馈为“每日一次＋每次更换耗材时”，并提出总厂也需要相关管理。总厂是否完整沿用驻点的频率和差异预警规则，仍需明确，不能直接扩大适用范围。

### 8.2 已体现的主要痛点

- **传票保存与查询困难**：纸质传票数量大，需要人工查找。
- **工作量统计耗时**：月底翻查传票并汇总姓名、工序和完成量。
- **信息重复填写**：生产及包装环节存在抄写、手写工作。
- **人员与数量变化灵活**：多人分担、临时换岗和补记使记录更容易滞后；这是由现场情况推导的管理关注点，尚无量化数据。
- **生产进度不能只看整单**：存在部分在制、部分交付，后续系统需要表达这种情况。
- **跨地点生产需要协调**：总厂与驻点可以分工并汇合，不能只记录一个单一生产地点。

来源：原文项目背景、第7.12—7.14节、第8.6节及客户新增设备管理要求。
